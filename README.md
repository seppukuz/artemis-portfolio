# artemis-portfolio
CS Portfolio containing security assessment reports and refactored code for Artemis Financial.

# Client Summary & Software Requirements
Artemis Financial is a financial services company that needed a security review on their software application. They wanted to find any existing vulnerabilities in their codebase and fix them so financial data and customer information stay secure against potential threats.

# What Went Well & Importance of Secure Coding
Finding the vulnerabilities went well once I got a clear process down for reviewing the code. Secure coding is important because even minor mistakes in code can open up big security risks. Keeping software secure protects sensitive data and keeps the company running smoothly without risking a data breach.

# Challenging and Helpful Parts of the Assessment
The most helpful part was seeing how vulnerabilities actually show up in real code and learning how to spot them. The hardest part was digging through the application to figure out how data flowed and finding where potential injection points or flaws were hidden.

# Layers of Security & Mitigation
Security was improved by adding better input validation, securing data handling, and using stronger encryption. For future projects, I'd rely on static analysis tools and standard security checklists to help catch vulnerabilities and pick the right fixes.

# Ensuring Functionality and Checking for New Vulnerabilities
I tested the app after making changes to make sure everything was still working like it was supposed to. After refactoring the code, I ran additional checks and re-ran analysis scans to make sure I didn't introduce any new security issues while fixing the old ones.

# Helpful Resources, Tools, and Practices
Using static code analysis tools and referring to standard security guidelines were the most useful practices, and those will definitely help in future programming tasks.

# Showcase for Employers
This project is a good piece to show employers because it demonstrates practical experience in finding, explaining, and fixing security vulnerabilities in software code.
